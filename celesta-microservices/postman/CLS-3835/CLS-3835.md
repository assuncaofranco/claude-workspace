# CLS-3835 — gateway default bonus list page size

**Feature:** `GET /bonuses` and `GET /reward/bonuses` without `limit` return the first 50; `limit` goes from 1 to 1000, anything above is 400.

## Setup
- Gateway on `CLS-3835` (local) or deployed (pp1). After a branch switch, clear `var/cache/dev` in `gateway.php` and restart it.
- `./run.sh` (local) or `./run.sh pp1`. Run the whole collection in one go: folders share captures.
- Postman UI: import, fill the credential vars, run in order with No environment.

## Steps
0. Player token; count the player's bonuses with `?limit=1000`.
1. BO: if under `minBonuses`, create a `free` manual config, enable it, offer until the player has `minBonuses` (skipped otherwise).
2. GW `/bonuses`: no params = first 50 of the full list; `limit=60`; `offset=50`; `limit=2&offset=51`; blank `limit=`; `limit=0|-1|abc|1001` and `offset=-1` = 400; `statuses[]=offered` cut at 50 after filtering; `statuses[]=claimed` (under 50) whole.
3. GW `/reward/bonuses`: no params = 50; `limit=60`; `limit=0` and `limit=1001` = 400.

## Variables
| Variable | Example | What it is |
|---|---|---|
| `baseUrl` | `http://localhost:93` | gateway |
| `BO_baseUrl` | `http://localhost:84` | backoffice |
| `minBonuses` | `60` | how many bonuses the player must have before step 2 |
| `username` / `password`, `oauth_client_*`, `BO_*` | | from the vault, never in the file |

Captured at runtime: `access_token`, `playerId` / `domainId` / `currency` (from the player JWT), `BO_access_token`, `toOffer`, `rcId`, `fullIds`, `offeredIds`, `claimedIds`, `rewardIds`.

## Notes
- PO-runnable as is: only gateway and BO, no internal service.
- Every check compares against the same list fetched with an explicit `limit`, so order and content are checked, not just the count.
- `limit=1000` is accepted: every reference request uses it.
- Synthesized automatic offers are not covered: they need a player with an `automatic` config, so they don't show up in this setup.
- Step 1 leaves an enabled `qa3835-*` config and offered bonuses on the player.
- pp1 already has the setup done: lucastest@gmail.com got 59 offered bonuses on 2026-10-19.
