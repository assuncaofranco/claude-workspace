# CLS-2847-CLS-2848 — How to test (bonus routing without `move_bonus_to_promotion`)

**Feature:** backoffice and gateway no longer read the flag; every bonus endpoint goes to promotion.

## Setup
- Stack up with backoffice and gateway on `CLS-2847-CLS-2848`; promotion, wallet, game on `master`.
- Local only: player 1 has a 1 EUR/day deposit limit in the fixtures. Raise it, or the deposit steps stop at the limit check:
  `UPDATE wallet.responsible_gaming_limit SET amount=100000, delayed_amount=NULL WHERE wallet_id=1 AND type='deposit'`
- Run `./run.sh` (it pulls credentials from the vault), folders 1 to 7, then drain the bulk queue, then folders 8 and 9:
  `docker compose -f docker-compose.dev.yml exec -T php php bin/console messenger:consume backoffice_bulk_action_sqs --limit=1 --time-limit=60` (inside celesta-backoffice)
- Folder 8 needs the id from folder 7: `./run.sh --folder "8 ..." --env-var bulkActionId=<id>`.

## Steps
1. BO: create (free, free_rounds), get, edit, enable, search (both routes), count, thumbnail.
2. BO: autocomplete `bonus_configuration` finds the promotion config, not the wallet bonus model.
3. BO: offer, list, count, cancel, read cancel back.
4. BO: promotion reward with an unknown `bonusModelId` gets 400; with a promotion id gets 200, then deleted.
5. BO: offer two free bonuses and one deposit bonus (min 10, max 100) to the player.
6. GW: list, claim, cancel, read back; deposit 5 is rejected by the bonus condition, deposit 20 passes it.
7. BO: bulk action offer_free_bonus, create and process.
8. BO: bulk item `done` with no errors (after the worker).
9. BO: create, delete, GET gives 404.

## Notes
- Every step runs through BO or gateway, so it works in pp1. The only manual step is draining the bulk queue.
- The deposit of 20 passes the bonus check and then gets a 502 from the payment provider locally. That is expected; the step only asserts the bonus check.
- The first promotion request after a cache rebuild can return an xdebug deprecation instead of JSON, which shows up as a 500 in BO. Rerun.
