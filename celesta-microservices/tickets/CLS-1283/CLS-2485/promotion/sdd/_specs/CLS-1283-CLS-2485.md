# Spec: CLS-1283-CLS-2485

branch: CLS-1283-CLS-2485

Promotion part of the MoveBonusCleanup "remove jobs and handlers". Wallet and job-library parts live in their own repos under the same branch name. Supersedes the promotion half of CLS-1283-CLS-1624, which was closed without merge.

## Summary

Two handlers survive from the migration of bonus status to promotion:

- **`BonusRollbackJobHandler`** consumes `BonusRollbackJob`, which wallet sends on a sportsbook bet rollback together with `BonusBalanceRestoredJob` for the same PLAYED→CLAIMED transition (same FIFO group, Restored first). The wallet half of this ticket stops sending it.
- **`BonusPlayedJobHandler`** is a BC shim for `BonusPlayedJob`, which has had no producer since CLS-392-CLS-849. Zero dispatches in 30 days of APM.

Both handlers only act on a `played` bonus, same as `BonusBalanceRestoredJobHandler`, and PLAYED→CLAIMED is a valid transition in `BonusConstants::STATUS_TRANSITIONS`. So the remaining handler covers every case the removed one did.

## Preconditions

- Wallet CLS-1283-CLS-2485 deployed to every env, so nothing produces `BonusRollbackJob` anymore.
- `promotion-bonus.fifo` drained of `BonusRollbackJob`. Observed rate: 1 in 30 days, prod-2 only.
- `promotion-failed` triaged: any `BonusPlayedJob` / `BonusRollbackJob` there is discarded, since it becomes unreplayable.

## Events / Async Messages

- Delete `BonusRollbackJobHandler` and `BonusPlayedJobHandler`.
- Update `docs/service-boundary.yaml`: drop `bonus-rollback` and `bonus-played`.
- Require `lancasters/job-library:dev-CLS-1283-CLS-2485`, switched to the tag before merge.

## Acceptance Criteria

From `tickets/CLS-1283/CLS-2485/matrix.md`, signed off 2026-10-16.

1. Given a `played` bonus, when a `BonusBalanceRestoredJob` for it is handled, then the bonus is `claimed` (the existing rollback scenario now drives this handler).
2. Given a bonus that is not `played`, when the same job is handled, then it is left unchanged.
3. No reference to the two handlers or the three job classes left in promotion. `lancasters/job-library` points to `dev-CLS-1283-CLS-2485` during review and to the release tag before merge.
4. All existing tests pass.

## Possible Edge Cases
