# CLS-1283-CLS-2485 — SB bonus rollback and BO cancel

**Feature:** after removing `BonusRollbackJob`, a sportsbook rollback still restores a played promotion bonus to claimed (via `BonusBalanceRestoredJob`), and the BO cancel still cancels in promotion and wallet.

## Setup
- Wallet, promotion, backoffice and gateway on the `CLS-1283-CLS-2485` branches (wallet, promotion) / master (BO, GW).
- `./run.sh`. Not runnable from the Postman UI as is: it consumes the promotion queue between parts.

## Steps
0. GW reads player balance; BO `adjustment_up` only if withdrawable is negative.
1. BO: create a `free` / `wager` reward configuration, enable it, offer bonus R (10 EUR) and C (5 EUR).
2. GW: player lists and claims R and C, reads the bonus balance.
3. DEV-ONLY wallet: sportsbook bonus bet of the whole bonus balance.
4. (consume `promotion_bonus_sqs`) BO: R and C are `played`.
5. DEV-ONLY wallet: roll the bonus bet back.
6. (consume `promotion_bonus_sqs`) BO: R and C are `claimed` again.
7. BO: cancel C; R still `claimed`, C `canceled`. DB: wallet sub_balance of C `canceled`.

## Notes
- Steps 3 and 5 are the sportsbook provider calling wallet: DEV-ONLY, not PO-runnable. In preprod the same check needs a real SB bet on a sportsbook domain (216).
- `run.sh` sets wallet `application.vertical` of domain 1 to `["casino","sb"]` for the run and back to NULL on exit.
- `roundId` must be new per run: wallet dedups sportsbook transactions by `roundId` and silently returns 200 with no change.
- `model: direct` turns the bonus into cash on claim (no bonus balance); use `wager` (needs `maxWinMultiplier`).
- GW `/bonuses` doesn't list `played`; BO `/bonuses` does only with `filter[statuses][]`.
- Folder 0: if player 1's EUR withdrawable is negative, wallet rejects every claim with 400 and promotion only logs it (bonus `claimed`, nothing in wallet). The collection then tops it up with a BO `adjustment_up`; otherwise the request is skipped. No fixture or DB change needed.
- Last run: 34 assertions, 0 failures; promotion log has no `NoHandlerForMessage` / `BonusRollbackJob`.
