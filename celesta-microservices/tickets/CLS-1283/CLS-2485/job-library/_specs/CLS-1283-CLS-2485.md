# Spec for CLS-1283-CLS-2485

branch: CLS-1283-CLS-2485

## Summary

Remove the three legacy bonus status jobs left over from moving bonuses to promotion: `JobLibrary\Job\Promotion\BonusPlayedJob`, `BonusRollbackJob` and `BonusClaimedJob`. Their replacements, `BonusBalanceDepletedJob` and `BonusBalanceRestoredJob`, stay.

## Functional Requirements

- Delete the three classes and `tests/JobLibrary/Job/Promotion/BonusRollbackJobTest.php`.
- Tag a new release. Wallet and promotion require `dev-CLS-1283-CLS-2485` during review and switch to that tag before merge.

## Possible Edge Cases

- **Messages still in a queue** become undeserializable once a consumer runs the new version. Tag this release only after the wallet and promotion branches are deployed and `promotion-bonus.fifo` / `promotion-failed` hold no message of these classes (see the promotion spec).
- **Other consumers**: at 2026-10-16, only wallet and promotion reference these classes across every Celesta service.
