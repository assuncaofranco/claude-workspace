# CLS-3507 — numerical custom attributes (BO)

**Feature:** player custom attribute `numerical` pelo BO: criar, gravar valor, recusar inválido, type travado.

## Setup
- Bundle `CLS-3791`, crm `CLS-3507-CLS-3793` e BO `CLS-3507-CLS-3796`, os três com `dev-CLS-3791 as 2.7.0`.
- PP1: crm sobe antes do BO.
- Rodar a coleção inteira, numa invocação só (ordem importa).
- Credenciais do BO via `--env-var`, do vault (`celesta-dev.md` local, `celesta-preprod.md` PP1).

```bash
newman run CLS-3507.postman_collection.json \
  -e CLS-3507.pp1.postman_environment.json \          # só no PP1
  --env-var BO_oauth_client_id=... --env-var BO_oauth_client_secret=... \
  --env-var BO_username=... --env-var BO_password=...
```

## Steps
1. Token do BO
2. Cria `<prefix>_points` numerical, default `0`
3. Cria sem `type` → `string`
4. `image` em player → 400
5. Default `abc` → 400
6. Lista: default `0` como número
7. PATCH `120`, `2.4`, `-5`, `2.50` → números, `2.50` vira `2.5`
8. PATCH `2.456` e `abc` → 400
9. Lista: continua `2.5`
10. PUT com `type: string` → segue `numerical`; PUT default `abc` → 400
11. PATCH `null` → `null`; lista mostra `null`
12. `numerical` em game e reward_configuration → 400
